📌 Description

This project focuses on developing an automated PCB (Printed Circuit Board) defect detection system using YOLOv8, a state-of-the-art object detection model. The system is trained to accurately identify and classify common PCB defects such as Missing Hole, Mouse Bite, Open Circuit, Short, Spur, Spurious Copper, and Good boards. It aims to enhance quality control in manufacturing and aligns with Industry 4.0 smart factory standards.

Technologies Used
Python
YOLOv8 (Ultralytics)
OpenCV
NumPy
Matplotlib
Deep Learning / Computer Vision

⚙️ Workflow

Dataset Collection & Annotation – Gather PCB images and label defects using annotation tools.
Data Preprocessing – Resize, normalize, and organize data for training.
Model Training – Train YOLOv8 on labeled PCB defect dataset.
Model Evaluation – Validate performance using metrics like accuracy and mAP.
Defect Detection – Run inference to detect and classify PCB defects in real-time images.
Visualization – Display detected defects with bounding boxes and labels.

🎯 Features
Real-time PCB defect detection
Multi-class classification of defects
High accuracy with deep learning
Scalable for industrial applications
